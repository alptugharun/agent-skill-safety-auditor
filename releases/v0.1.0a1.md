# Agent Skill Safety Auditor v0.1.0a1

First public alpha release of the offline Agent Skill pre-install scanner.

## What it does

The CLI scans a local Agent Skill directory for evidence that deserves human review, including:

- remote content piped to shell;
- PowerShell download-and-execute patterns;
- SSH/browser credential references;
- recursive destructive deletion;
- dynamic execution;
- subprocess/shell usage;
- network access;
- environment-variable reads;
- encoded payload handling;
- Node package lifecycle hooks.

Findings are evidence for review, **not a malicious/safe certification**.

## Install the signed wheel

Download/install the exact release wheel:

```bash
python -m pip install "https://github.com/alptugharun/agent-skill-safety-auditor/releases/download/v0.1.0a1/agent_skill_safety_auditor-0.1.0a1-py3-none-any.whl"
```

Then:

```bash
skill-audit --help
skill-audit path/to/skill
```

## Verify the download

The release includes:

- the wheel;
- `SHA256SUMS.txt`;
- Sigstore `.sigstore.json` bundles for the wheel and checksum file.

A signature/checksum proves integrity/identity for the signed bytes. It does not prove the scanner or a scanned skill is vulnerability-free.

## Security boundary

The scanner is designed to run offline and should not execute the target skill.

A clean scan does not detect future remote-service behavior drift. Runtime sandboxing, egress controls, allowlists and least privilege remain separate layers.

## Evidence

Before release preparation, the wheel was built on Windows, installed into a clean virtual environment, the `skill-audit` console command was invoked successfully, and the package import succeeded.

The release workflow repeats tests/build/install verification on Ubuntu before publishing.

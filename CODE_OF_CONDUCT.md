# Code of Conduct

Be respectful, specific, and evidence-led.

This project welcomes bug reports, false-positive/false-negative reproductions, parser hardening, security research, and focused pull requests.

Critique the code, detection rule, or documentation — not the person.

Harassment, threats, doxxing, spam, credential sharing, and deliberate exposure of private data are not acceptable.

For moderation or sensitive security concerns, use a private contact path instead of posting private material in a public issue.
